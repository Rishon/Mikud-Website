### What is a mikud?

Mikud (מיקוד) is the Hebrew name for an Israeli zip code: a seven-digit postal code that Israel Post assigns to addresses in Israel. It is used to sort and deliver letters and parcels, and it is also required on forms, online shopping checkouts and international shipments.

### How do I find a zip code by address?

- Start typing the city or town and pick it from the list.
- Type the street name and pick it from the list.
- Enter the house number, and the entrance if the building has more than one.
- Click "Find zip code" and the zip code appears right away. Click the result to copy it.

### Why do addresses in the same city have different zip codes?

In large cities the zip code depends on the street and house number, so different buildings on the same street can have different zip codes. Smaller towns usually have a single zip code for the whole town. To get the exact code, always search by the full address, or [pick a town from the list](/cities) to browse its streets.

### What is the difference between 5-digit and 7-digit Israeli zip codes?

In February 2013 Israel Post moved from five-digit zip codes to seven-digit ones, which allow more precise sorting. The seven-digit code is the one in use today, and it is the one to use for every address.

### What do I enter in a Zip Code or Postal Code field?

For an Israeli address, Zip Code and Postal Code both mean the mikud. Enter the seven digits without spaces or dashes.

### What is the zip code of a PO box?

PO boxes have their own zip codes, different from the street address. This site finds zip codes for street addresses; you can get the zip code of a PO box from Israel Post.

### Is the service free?

Yes. Searching is free and needs no sign-up. Zip codes come from Israel Post's zip code lookup service, and your recent searches are kept only in your browser.
